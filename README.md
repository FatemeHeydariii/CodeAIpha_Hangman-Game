Hangman Game

A simple Hangman word-guessing game built with Python as part of my CodeAlpha Python internship.

How It Works

- The program randomly selects a word from a list.
- The player guesses one letter at a time.
- Correct letters are displayed in their positions.
- Incorrect guesses reduce the player’s 6 attempts.
- The Hangman drawing is updated after each wrong guess.
- The game ends when the word is guessed or all attempts are used.
